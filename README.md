# S64 Fullstack Challenge

This repo provides a template for you to tackle the S64 programming challenge.

The requirements are in the Requirements.md file. Please read it carefully.

You are not required to use these technology choices to meet the requirements if you have a different preferred
stack. However, we ask that you use React and Typescript in your answer even if you make other changes.

The data is in the `backend/data/planes.sqlite` file.  It can be read using the sqlite3 package from npm.

## Prerequisites

- Node >= v18
- NPM >= 9

## Setup for Development

Install dependencies with ```npm install```.

Run the frontend:
```bash
cd frontend
npm run dev
```

Run the backend:
```bash
cd backend
npm run dev
```

## Templates

### Frontend

The frontend template is based on the `react-ts` template provided by [Vite](https://vitejs.dev/).

Please complete the front end portion of the assessment using React and Typescript.

### Backend

The backend template provides the basic setup for an Express server using Typescript.

This is provided for convenience, however you are under no obligation to use Express
if there is a different technology you are more familiar with.
